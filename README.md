# Agricultural Commodity Price Prediction

## 🌾 Overview
This project uses Linear Regression to predict the modal price of agricultural commodities based on features like crop type, market location, and arrival quantity. It aims to support farmers and traders with price forecasting.

## 🛠️ Tools & Technologies
- Python
- Pandas
- Matplotlib & Seaborn
- Scikit-learn
- Jupyter Notebook

## 📊 Model Summary
- Trained a Linear Regression model on agricultural market data
- Explored relationships between crop arrival and modal price
- Visualized trends and regression line

## 📁 Files
- `linear_regression_model_with_agriculture_dataset.ipynb`: Main notebook with data analysis and model training
- `README.md`: Project summary and instructions

## 🚀 How to Run
1. Clone the repo
2. Install dependencies: `pip install pandas matplotlib seaborn scikit-learn`
3. Open the notebook in Jupyter
4. Run cells sequentially to view predictions and visualizations

## 📌 Use Case
Useful for agri-tech startups, government policy analysts, and rural market researchers to forecast prices and support decision-making.
